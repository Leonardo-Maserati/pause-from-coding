Upcoming Project: Japanese Learning Platform
As soon as the exams are over, activity here will resume at full speed. I will focus on building a free website (or web app) designed for those who, like me, want to approach the Japanese language in an effective yet simple way. It won’t be a complicated piece of software, but a clean environment where you can learn the basics through:

· Syllabaries with mnemonics: a guide to Hiragana and Katakana that uses visual associations to make memorization much faster than the classic method.

· The 100 most basic Kanji: a selection of the first essential characters for complete beginners, organized in a way that doesn’t discourage the student.

· An intuitive interface: an essential space, without too many distractions, focused solely on learning.

This project is an important milestone for me: it is a practical exercise that allows me to combine my passion for languages with my passion for programming. If everything goes according to plan, it will be one of the first building blocks in my path to becoming, one day, a software engineer.
